# CLAUDE

Espacio de trabajo personal para colaborar con [Claude Code](https://claude.ai/code), el CLI de Anthropic.

## Que es esto

Esta carpeta es el directorio raiz desde el que se ejecuta Claude Code. Aqui se almacena la configuracion del agente y los proyectos en los que trabajamos juntos.

## Estructura

```
CLAUDE/
├── .claude/          # Configuracion interna de Claude Code
└── README.md         # Este archivo
```

## Como usar

1. Abre esta carpeta en tu terminal
2. Ejecuta `claude` para iniciar una sesion
3. Dale una tarea y colabora

## Requisitos

- [Claude Code](https://claude.ai/code) instalado
- Cuenta de Anthropic activa
